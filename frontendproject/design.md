1. Project Design (Planning & Architecture)

Project design means how your project is structured, organized, and built before you actually implement it. For your Old Vehicle Sale website, project design can include:

🔹 a) Requirements

->Users can view vehicles (with details like name, model, year, price, description, image).

->Users can book a vehicle (form with name, phone, address, confirm/cancel buttons).

->Users can wishlist vehicles for later.

->Admin can add, edit, delete, and manage vehicles.

Responsive layout (works on mobile & desktop).

🔹 b) System Architecture

Frontend (UI):

HTML, CSS (media queries, responsive design).

JavaScript (for booking, cart logic).

Admin panel for CRUD operations.

Pages:

index.html -> main page of project.

home.html-> it is showing home page of project.

vehicles.html -> All vehicle listings (with "Book Now" & "Wishlist").

cart.html ->user's saved (favourites) vehicles.

auth.css-> authentication page for login,signup.html(checking user valid entry with email and new entry).

booked.html->booked vehicles data shown.

admin.html -> Manage new vehicles data (add/edit/delete).

about.html -> About us page.

contact.html -> Contact form.

login.html-> login page for customer,vehicle buyers,(normal peoples).

signup.html->signup page for customer,vehicle buyers,(normal peoples).

Navigation: One common navbar with 6 links + 3 buttons (like Home, Vehicles,Cart, Booked,Admin,About, buttons->Contact, login,sign up).
