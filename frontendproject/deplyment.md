2. Project Deployment (Making It Live)

Deployment means making your project available to users on the internet.

🔹 Options for Deployment

Static Deployment (Frontend only)
If your project is just HTML, CSS, JS -> You can host it for free:

GitHub Pages

Netlify

Vercel

Steps (Example GitHub Pages):

Push project to GitHub.

Go to repo → Settings → Pages → Select branch → Deploy.

Your site will be live at https://username.github.io/old-vehicle-sale.

Frontend: Netlify or Vercel.
